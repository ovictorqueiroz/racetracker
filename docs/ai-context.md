# Sobre o projeto
RaceTracker é uma aplicação web para acompanhar o calendário de eventos de automobilismo das principais categorias mundiais e nacionais (Brasil) como:

- Fórmula 1
- Nascar
- IndyCar
- Stock Car
- WEC
- Entre outros

| O projeto está sendo desenvolvido como projeto pessoal para portfólio

## Objetivo
Criar uma plataforma rápida, simples, visualmente moderna e agradável, e bastante intuitiva para acompanhar: próximas corridas, calendários, horários locais e o canal de transmissão de cada evento.
