# RaceTracker

## O que é?
O RaceTracker tem o objetivo de responder à seguinte pergunta: -“Tem corrida hoje?”

Para o fã de velocidade que acompanha mais de uma categoria como F1, WEC, IMSA e Nascar, além de categorias nacionais, como Stock Car e Porsche Cup, acompanhar o calendário individual de mais de uma categoria pode ser um grande desafio.

É aí que entre o RaceTracker!


## Objetivo
Exibir de forma rápida e fácil, direto na tela ou em forma de agenda, as datas e horários das categorias escolhidas pelo cliente.

## Stack utilizada

- CSS (Tailwind)
### BACKEND
